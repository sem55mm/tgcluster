# tgcluster

Интерактивное управление Telegram-аккаунтами в терминале (Telethon).
Все файлы сессий хранятся в папке `sessions/` рядом со скриптом.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
./tg_manager.py
```

Открывается меню:

```
══════════════════════════════════════════════════════════════════
  TG Manager   аккаунтов в sessions/: 2
══════════════════════════════════════════════════════════════════

  1) Аккаунты: список и статус
  2) Добавить аккаунт (вход по номеру)
  3) Отправить сообщение
  4) Вступить в чат/канал
  5) Выйти из чата/канала
  6) Инфо об аккаунте
  7) Удалить аккаунт / logout
  8) Настройки
  0) Выход
```

Всё управление — стрелками не нужно: вводится номер пункта, Enter подтверждает.

### Аккаунты

При первом запуске скрипт попросит `api_id` и `api_hash`
(бесплатно на https://my.telegram.org → API development tools) и сохранит их
в `config.json`. Дальше пункт **2** спрашивает телефон, код из Telegram и пароль
2FA, если он включён, и создаёт `sessions/<имя>.session`.

Пункт **1** подключается к каждому аккаунту и показывает статус:
`✓ spare   @nick · +79991234567 · id=123`, либо `✗` с причиной
(«не авторизована», «сессия отозвана», `FloodWait` и т.п.).

### Выбор аккаунтов

В пунктах 3–7 сначала показывается список с номерами, затем вводится выбор:

```
Номера (1,3 или 1-3), all, Enter — отмена
```

- `1,3` — первый и третий
- `2-4` — диапазон
- `all` — все аккаунты
- пустой Enter — отмена

Операции выполняются параллельно, прогресс и ошибки печатаются по каждому
аккаунту: `[ok] work: отправлено в @chat (2/3)`.

### Что делают пункты

| Пункт | Действие |
| --- | --- |
| 3 | отправка сообщения от выбранных аккаунтов; текст можно ввести строкой или взять из файла |
| 4 | вступление в чат/канал: `@username`, `t.me/...` или ссылка-приглашение `t.me/+...` |
| 5 | выход из чата/канала |
| 6 | подробности по одному аккаунту: имя, username, телефон, premium, «о себе», число общих чатов |
| 7 | удаление сессий, по желанию с `logout` на стороне Telegram |
| 8 | настройки: api_id/api_hash, прокси, параллельность, пауза |

### Настройки (пункт 8)

- **прокси** — `socks5://user:pass@host:port` (или `socks5://host:port`, `http://...`), общий для всех аккаунтов;
- **параллельно** — сколько аккаунтов работают одновременно (по умолчанию 3);
- **пауза** — задержка в секундах перед каждым аккаунтом, помогает не ловить `FloodWait`.

Всё это пишется в `config.json` рядом со скриптом. Флаги запуска
(`--api-id`, `--api-hash`, `--proxy`) лишь переопределяют его на один запуск:

```bash
./tg_manager.py --proxy socks5://127.0.0.1:1080
```

## Замечания

- `sessions/` и `config.json` в `.gitignore`: файл сессии — полный доступ к аккаунту,
  его нельзя коммитить или передавать.
- Отправка сообщений и вступление в чаты должны укладываться в
  [правила Telegram](https://core.telegram.org/api/terms): массовые рассылки
  незнакомым людям ведут к блокировке аккаунтов.
